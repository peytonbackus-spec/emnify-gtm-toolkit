# Glossary

- **Hypothesis: validate**: an assumption about emnify that has not been checked with the team.
- **Waterfall**: ordered data providers per field; the first value at or above the confidence floor wins.
- **Fit gate**: no vertical match, no paid contact credits.
- **Expected usage revenue**: devices x data per device x price x months, shaped by a ramp, always a range.
- **Coverage ratio**: open pipeline in expected-usage terms divided by the remaining target.
- **Usage realization**: realized divided by expected usage revenue for a cohort.
- **Speed to lead**: minutes from first qualifying signal to first human touch.
- **HITL gate**: the point where a person accepts, modifies or ignores a proposal.
- **Dead letter**: where an operation lands after retries are exhausted.
- **Workflow contract**: a declared purpose, steps, human gate, kill switch and metrics for an automation.
