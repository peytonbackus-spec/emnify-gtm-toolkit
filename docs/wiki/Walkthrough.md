# Walkthrough

A ten-minute talk track that follows one synthetic account from signal to Salesforce: dedupe, the Clay table with its fit gate, the waterfall, mapping and write policy, scoring, coverage, agent proposals, then the human gate and n8n. It ends with the first four weeks and the likely pushback with answers.
